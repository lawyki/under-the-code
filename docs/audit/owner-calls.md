## The Bridge

- **Fig BR.3 (fig-br-3), fact H.** (1) The SOURCE box "SYSCALLS · SYSCALL or int 0x80" draws SYSCALL as an IDT source; chBridge-trap-p4 and §4g's system-call row say SYSCALL jumps through MSR_LSTAR and skips the table. (3) The handler names are pre-5.8 (now exc_* and sysvec_*). Recommended: SOURCE box "int 0x80 (legacy) · user request"; drop the numbers on the two hardware rows ("…"); optionally "e.g." before the handler names.
- **Fig BR.3 caption (chBridge-trap-p5).** "When any trap fires, the CPU reads the IDT …" is false for SYSCALL, the trap Fig BR.2 just showed. Recommended: "When an exception, an interrupt or an int instruction fires, the CPU reads the IDT base address from its IDTR register, indexes by vector number, and jumps to the handler the kernel registered for that vector." The last sentence ("every involuntary entry") is true as it stands (SYSCALL is voluntary).
