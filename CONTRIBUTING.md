# Contributing

This is a written work, not software. It is licensed CC BY-NC 4.0.

## What is accepted

- Typo and grammar corrections
- Broken-link reports
- Factual corrections with citation
- Chapter translations (CC BY-NC 4.0 permits derivatives with attribution)

## What is not accepted

- Edits to argument, framing, or chapter structure
- Stylistic rewrites
- Additions of new material

The work has a single author. Editorial direction is not open.

## How to submit

- Corrections: open an issue with chapter and section reference.
- Translations: open an issue first to coordinate scope and attribution.
  Translations live in their own branch or fork; this repository hosts the
  English source only.

## Style

- Prose follows the existing voice. Do not rewrite for tone.
- Citations: footnote style consistent with the surrounding chapter.
- Commits: imperative mood, present tense.
